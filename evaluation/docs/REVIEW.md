# Scientific scope and interpretation

Q1 retains two frozen physical contracts: LEGACY_V0.2 and MIXED_V0.3. Report these
families separately. Its original reviewed 200 Cases and quota-based expansion
include difficulty selection and seeded spectrum variants; this is not a random
sample of natural traffic. Beam failures alone do not establish model difficulty.
Model-assisted selection must be disclosed; the set is not unseen by models used
in that selection. Shared topologies and related task projections are dependent.

Q1 uses the frozen ASE-only/CD and guard assumptions. NLI, device-level QoT and
incumbent QoT interactions are outside this model. Secondary tolerance is 1e-10;
O/X gap classification keeps 1e-9. Weighted G3/X1 use printed link-length precision.

Reference replay verifies stored answers against the frozen scoring code. It
does not rerun the global oracle optimizer or independently prove all optima.
Historical X3 joint-certificate and secondary-optimality audit limitations remain
outside the explicitly rechecked scopes. Existing source interface/objective
REVIEW flags remain in force; they must not be silently counted as model failures.

Only final visible answers are graded. Strict scoring preserves the response;
relaxed scoring removes one outer JSON fence. Source parsing and numerical rules
are preserved, including nested-parser errors reported as SCORING_ERROR. Report
model categories, certified rejection, REVIEW states and service errors separately.

Directory normalization changes current location metadata and integrity bindings;
scientific payloads, prompt bytes, source IDs, UIDs and scoring Python are not
changed. The OptiRA namespace uses optira; frozen legacy compatibility identifiers
inside vendored source are historical protocol values, not active package names.
Check UID and public-message hash when joining historical results, not display IDs.

Stored references are downloadable in the public dataset. Private denotes their
grading role, not confidentiality. Model inputs must exclude them. Code is licensed under MIT; data under CC BY 4.0. Retain applicable
source notices and third-party terms when redistributing.
