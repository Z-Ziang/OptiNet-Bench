# Scientific scope

Q1 includes pure-200G and mixed-rate physical models. Its 2,000 Cases are
selected by stratified sampling over joint quota strata defined by exact node
count, rate mode, frozen physical contract, request count and Oracle decision,
rather than a uniform random sample. The paper's 200 evaluated Q1 Cases are a
stratified sample of these 2,000. Shared topologies and related task projections
are statistically dependent.

The QoT model includes ASE noise and chromatic dispersion under the specified
guard assumptions. Nonlinear interference, device-level QoT and interactions
with incumbent-service QoT are outside its scope. Q1 uses a secondary-objective
tolerance of 1e-10; O1/X2/X3 use a classification gap tolerance of 1e-9.
Weighted graph tasks use the link-length precision shown in their prompts.

A legal submitted solution improving on the reference optimum is a reference
conflict requiring inspection, not a model failure. Reference validation checks
stored answers against the grading implementation; it does not independently
rerun the global optimizer. Only final visible answers are graded.

References are publicly downloadable. The `private` directory name identifies
their grading role, not access restrictions. Never include grading references
in model inputs. Retain applicable attribution and third-party license terms.
